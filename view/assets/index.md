# Assets

This folder contains the authenticated settings page used to manage assets, view groups, display preferences, and password or data export.

## Files

- [index.html](./index.html): Settings page markup for editable asset tables, view-group management, the hide-absolute and compact absolute-values preference toggles, plus password and full-data export controls.
- [script.js](./script.js): Client-side asset editing, validation, persistence, display-preference wiring, and password or full-data export behavior.
- [styles.css](./styles.css): Page-specific layout and control styling for the settings view, including the display-preferences toggle row.
