# Assets

This folder contains the authenticated settings page used to manage assets, view groups, and password export.

## Files

- [index.html](./index.html): Settings page markup for editable asset tables, view-group management, and password export controls.
- [script.js](./script.js): Client-side asset editing, validation, persistence, and password export behavior.
- [styles.css](./styles.css): Page-specific layout and control styling for the settings view.
