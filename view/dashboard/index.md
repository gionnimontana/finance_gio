# Dashboard

This folder contains the main authenticated portfolio overview page and its page-specific rendering logic.

## Files

- [chart.js](./chart.js): Canvas-based pie chart rendering for portfolio totals by view group.
- [index.html](./index.html): Dashboard markup for overview cards, progress banner, and grouped portfolio output.
- [script.js](./script.js): Portfolio fetching, refresh streaming, cache reconciliation, and DOM rendering logic.
- [styles.css](./styles.css): Page-specific styling for overview cards, grouped rows, and the refresh progress banner.
