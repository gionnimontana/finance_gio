# Commons

This folder contains the frontend assets shared across every page in the application.

## Files

- [styles.css](./styles.css): Shared layout, sticky desktop header, mobile bottom navigation, banners, tables, summary cards, and privacy-toggle styling.
- [utils.js](./utils.js): Common auth, fetch, centralized currency-aware whole-number full-value or compact absolute-value formatting with a persisted settings preference plus opt-in forced-compact labels and no-currency overrides for exception views, privacy-aware percentage helpers, footer, banner, and privacy-toggle utilities.
