# Commons

This folder contains the frontend assets shared across every page in the application.

## Files

- [styles.css](./styles.css): Shared layout, sticky desktop header, mobile bottom navigation, banners, tables, and summary-card styling.
- [utils.js](./utils.js): Common auth, fetch, centralized currency-aware whole-number full-value or compact absolute-value formatting with persisted Settings preferences plus opt-in forced-compact labels and no-currency overrides for exception views, privacy-aware percentage helpers, shared ATH mood-title helpers, and shared footer and banner utilities.
