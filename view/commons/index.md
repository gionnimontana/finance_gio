# Commons

This folder contains the frontend assets shared across every page in the application.

## Files

- [styles.css](./styles.css): Shared layout, sticky desktop header, mobile bottom navigation, banners, tables, summary cards, and privacy-toggle styling.
- [utils.js](./utils.js): Common auth, fetch, whole-number full-value or compact absolute-value formatting with a persisted settings preference plus an opt-in forced-compact override for chart labels, privacy-aware percentage helpers, footer, banner, and privacy-toggle utilities.
