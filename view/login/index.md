# Login

This folder contains the unauthenticated entry page used to validate an existing password or create a new account.

## Files

- [index.html](./index.html): Login page markup for password entry, password generation, and feedback banners.
- [script.js](./script.js): Login validation, account generation, clipboard copy, and redirect logic.
- [styles.css](./styles.css): Page-specific styling for the login and generated-password states.
