# View

This folder contains the frontend pages, shared browser utilities, and page-specific styling used by the application.

## Folders

- [assets/index.md](./assets/index.md): Settings UI for assets, view groups, and password export.
- [commons/index.md](./commons/index.md): Shared frontend styles and browser utilities.
- [dashboard/index.md](./dashboard/index.md): Main portfolio overview page with refresh progress and pie chart rendering.
- [history/index.md](./history/index.md): Historical portfolio summary page with stacked chart and a scrollable monthly table that keeps its header visible.
- [login/index.md](./login/index.md): Login and account-generation page.
